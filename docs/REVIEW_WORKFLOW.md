# 人工审核工作流程（LeafByte 审核页）

本页给**不写代码的审核人**看。整个过程**不需要联网、不需要服务器**：双击一个 HTML 文件即可。
审核的对象是自动测量“不能确定”的叶片照片；你的决定会写进最终结果表。

## 1. 打开审核页

1. 管理员跑完自动测量后执行：

   ```
   leafbyte review --out out/
   ```

2. 双击打开 **`out/review/index.html`**（Chrome / Edge / Firefox 均可）。
3. 先在右上角填写**审核人姓名或工号**（导出时必填，会写进最终表的 `source`）。
4. 右侧“文件列表”就是所有需要人工确认的照片（`review` = 需复核，`failed` = 自动失败）。
5. 顶部进度条显示 `已审 / 总数 reviewed`。中途关掉浏览器也没关系：进度会保存在本机浏览器，
   重新打开会自动恢复；也可以点“导入 decisions.json”继续上次的工作。

## 2. 一张卡片看什么

| 区域 | 含义 |
| --- | --- |
| **原图** | 手机拍的原始照片。 |
| **原图 + 比例尺标注** | 黄色十字 = 自动识别的 4 个比例尺标记；黄色四边形 = 透视矫正范围。四个黄框都套住真正的黑色标记才可信。 |
| **矫正后 · 叶片(红)/啃食(蓝)** | 自动测量用的图。**红色 = 检测到的叶片**（含被啃食的洞）；**蓝色 = 计入 `consumed_cm2` 的被啃食洞**。 |
| **数字** | `total_cm2` 叶片总面积、`consumed_cm2` 被啃食面积、`percent_consumed` 啃食比例、`confidence` 自动置信度（0~1，越高越可信）。 |
| **flags / reason** | 自动判为可疑的原因（阈值不稳、贴边、比例尺质量差等）。 |
| **候选阈值** | 自动在 ±0.04 内多试了几档阈值，每个候选有自己的缩略叠加图和一组数字；点击缩略图选中（或按数字键 1–9）。 |

**判断重点**：红色区域是否正好覆盖整片叶子（不连到背景/阴影）；蓝色洞是否与真实虫咬洞一一对应；
黄色比例尺框是否套住 4 个黑点。

## 3. 颜色图例

| 颜色 | 含义 |
| --- | --- |
| 🟥 红色（半透明） | 检测到的叶片区域，含被啃食的洞 |
| 🟦 蓝色 | 被啃食的洞，计入 `consumed_cm2` |
| 🟨 黄色（十字 / 线框） | 4 个比例尺标记、矫正四边形范围 |

若红色跑到叶外、蓝色出现在叶片外，说明自动分割有问题：换候选或手填，必要时弃用。

## 4. 三种决定

| 操作 | 快捷键 | 什么时候用 | decisions.json 中记录 |
| --- | --- | --- | --- |
| **采纳候选** | `A` | 先在候选里选中一个：它的阈值和洞边界最贴合真实情况，就用它的数字作为最终值。 | `"action":"accept"` + `candidate_id` + `threshold` + 数字 |
| **采用手填数值** | `O` | 你自己量好了准确数字（如用 ImageJ），在“手填总面积 / 手填被啃食”里填数，再按 O。 | `"action":"override"` + 数字 |
| **弃用 / 需重拍** | `R` | 这张照片不可用；最终表里不留数值，请在备注写明原因。 | `"action":"reject"` + `note` |

说明：

- **只填数字不点按钮不算数**，必须按 `A` / `O` / `R`（或点按钮），卡片出现绿色“已记录”才生效。
- 没有找到比例尺时（`total_cm2` 显示“—”，只剩 `percent_consumed`）：只能按 `A` 采纳这个**相对比例**
  （不产生 cm²），或按 `R` 弃用。
- 操作错了按 `U` 或 `Ctrl+Z` 撤销；左侧点文件名可跳到任意一张。
- 采纳候选后仍可重新选候选再按 `A` 覆盖，或撤销后重做。

## 5. 哪些情况应当弃用（R）？

- 比例尺标记缺失、被遮挡、不在画面里、少于 4 个 → 无法换算 cm²；
- 照片模糊、过曝、强反光盖住叶片或比例尺；
- 叶片贴边 / 被裁切、撕裂严重、被其他东西遮挡；
- 背景不是白纸（有明显阴影、桌面纹理、多片叶子）；
- 虫咬洞与背景连通（洞不在叶片内部），或漏算/多算的洞换候选也修不好；
- 只剩 `percent_consumed` 且你无法判断洞的边界。

弃用时把原因写进“审核备注”，例如：`反光，需重拍`、`比例尺被手指遮挡`、`叶片超出画面`、
`洞与背景连通`。

## 6. 导出并交回 decisions.json

1. 填好右上角**审核人**姓名。
2. 随时点右上角 **⬇ 导出 decisions.json**（快捷键 `E`），浏览器会下载 `decisions.json`。
   - 格式固定为：`{"reviewer": 姓名, "reviewed_at": 时间, "decisions": {文件名: {...}}}`；
     只有已做决定的卡片在 `decisions` 里；中文备注按 UTF-8 保存。
3. 把下载的文件放回 **`out/review/decisions.json`**（覆盖旧的；文件名保持 `decisions.json`）。
4. 交给管理员执行：

   ```
   leafbyte apply out/ --decisions out/review/decisions.json --reviewer 你的名字
   ```

   最终结果表 `out/final_results.csv` 中，该图的 `source` 会变成 `review:你的名字`，
   并保留 `original_confidence` / `original_threshold` 便于追溯；`reject` 的图 `status` 为 `rejected`，
   不留最终数值。没审核的图保持 `review`/`failed`，下次可以继续审。

**注意事项**

- 不要改照片文件名，不要手改 JSON 结构；中文文件名/备注都没问题（UTF-8）。
- 关闭浏览器前建议先导出一次备份；同一台电脑重开页面会自动恢复本地进度，
  也可以“导入 decisions.json”接着做。
- 审核页与 `out/` 目录一起拷贝即可在另一台电脑打开（图片都是相对路径，页面完全离线）。

## 7. 快捷键速查

| 键 | 作用 |
| --- | --- |
| `←` / `→` | 上一张 / 下一张 |
| `1`–`9` | 选择第 1–9 个候选（再按一次取消选择） |
| `A` | 采纳候选（未选候选时用当前测量值） |
| `O` | 采用手填数值 |
| `R` | 弃用 / 需重拍 |
| `U` / `Ctrl+Z` | 撤销上一步决定 |
| `E` | 导出 decisions.json |
| `Esc` | 从输入框退出，回到快捷键状态 |
